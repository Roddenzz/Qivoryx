# Qivoryx — презентация приложения

Русский видеоролик, 1920 × 1080, 30 кадров/с, 3 минуты 6 секунд.

В ролике использованы реальные снимки интерфейса Qivoryx 0.3.0. Увеличения и переходы выполнены в Remotion. Графики лаборатории кадров содержат демонстрационные данные и явно отмечены в кадре. Сценарий не обещает гарантированный прирост FPS.

Озвучка: [ElevenLabs](https://elevenlabs.io), Arseniy, `eleven_multilingual_v2`, русский текст. Субтитры синхронизированы с посимвольной разметкой записи. Тихая электронная подложка создана программно специально для этого ролика, без сторонних музыкальных семплов.

## Просмотр и редактирование

```sh
npm ci
npm run dev
```

Главная композиция — `Qivoryx`. Отдельные сцены доступны в папке `Scenes`. Сценарий и субтитры находятся в `public/narration.txt` и `public/Qivoryx-RU.srt`; временная шкала — `src/timeline.json`.

Исходники приложения находятся уровнем выше. Node.js: 20.19+, 22.13+ или 24+. Готовые записи Arseniy находятся в `public/voice-arseniy`; для рендера не нужен доступ к ElevenLabs. Папки с другими голосами в репозиторий не включены.

## Экспорт

```sh
mkdir ../artifacts
npx remotion render src/index.ts Qivoryx ../artifacts/Qivoryx-Presentation-RU-Arseniy-raw.mp4 --codec h264 --crf 18 --audio-bitrate 192k --concurrency 4
python -m pip install -r requirements.txt
python scripts/finalize.py
```

Если `artifacts` уже существует, создавать её повторно не нужно. После `finalize.py` MP4, отдельный SRT и постер находятся в `../dist`, отчёт проверки — в `../artifacts/video-validation-Arseniy.json`. Финализатор проверяет полное декодирование, разрешение, число кадров, громкость и истинный пик. Для проверки исходников: `npm run lint`.

Готовый файл в папке `../dist` дополнительно приведён к громкости −16 LUFS, с ограничением истинного пика −1.5 dBTP. Видео при этом копируется без повторного сжатия.

Скрипт `scripts/eleven_voice.py` получает ключ только из переменной окружения `ELEVENLABS_API_KEY`. Ключ в исходниках и медиафайлах не хранится. Записи уже включены в проект: для просмотра и повторного рендера ключ не требуется.

Для обновления озвучки задайте `ELEVENLABS_API_KEY` в окружении текущего процесса, затем выполните:

```sh
python scripts/eleven_voice.py
python scripts/prepare_media.py --elevenlabs
python scripts/make_score.py
```

Генератор использует сохранённые MP3, если они уже существуют. Для повторной генерации конкретной сцены предварительно перенесите её MP3 и соответствующий `.words.json` из `public/voice-arseniy` в резервную папку. Голос задаётся константой `VOICE` в `scripts/eleven_voice.py`.

Длительности сцен вычисляются из готовых MP3 с учётом переходов. Внутренние переходы привязаны к временным меткам слов выбранной озвучки. Снимки интерфейса уже включены; если в `../artifacts/ui` есть свежие кадры, подготовка медиа обновит их копии. Для повторного использования другого голоса проверьте доступ к нему в своём аккаунте ElevenLabs и условия сервиса.

Во время производства ролика параметры Windows не изменялись, программы не устанавливались и не удалялись через Qivoryx.
