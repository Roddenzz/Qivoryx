# Qivoryx 0.3.0 — Windows Toolkit

**Ваш ПК. Под вашим контролем.** Нативный инструмент для диагностики, настройки Windows и сравнения игровых замеров. Русский интерфейс, тёмная и светлая темы.

## Возможности

- Диагностика CPU, памяти, дисков и процессов, центр оптимизации.
- Лаборатория кадров: PresentMon CSV, A/B, средний FPS, 1% low, P95/P99, графики и экспорт.
- Игровые сессии с временным планом питания и возвратом параметров.
- AMD/NVIDIA: рекомендации, сведения о драйверах и предпросмотр частоты дисплея.
- Автозагрузка, службы и тонкая настройка с поддерживаемым восстановлением.
- План питания для настольного ПК с описанием каждого параметра.
- 126 приложений: winget, очередь установки и проверяемые прямые загрузки.
- Удаление зарегистрированных программ и Appx, анализ и очистка временных файлов.
- Состояние защиты, отдельная интеграция внешнего инструмента, журнал операций.

## Требования и важные сведения

Windows 10/11 **x64**. .NET 8 включён в portable-сборку; установщик использует .NET Framework 4.8. Системные изменения могут потребовать UAC. Сборки не подписаны коммерческим сертификатом.

Сохраняйте все файлы portable-архива вместе. Папка `Data` переносит основные пользовательские данные; системные копии автозагрузки и восстановление сессий привязаны к исходному ПК.

Результат настройки зависит от оборудования и нагрузки; гарантированный прирост FPS не заявляется. Не все операции обратимы: перед очисткой, удалением программ и внешним удалением защиты подготовьте резервную копию. Внешний инструмент запускается видимо, с собственными диалогами. Защищённые компоненты Windows и региональные ограничения удаления Edge учитываются.

Сборка и интерфейс проверены без запуска разрушающих операций на основном ПК. Для проверки таких операций нужна отдельная виртуальная машина.
